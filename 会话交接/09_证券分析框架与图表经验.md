# 证券分析框架、推理手法与图表经验

2026-10-25整理。本文是本项目的综合方法与经验，不是新Fact账本或新增结论采纳。开始研究先读[当前交接](CURRENT.md)，接手实际操作读[快速接续](10_快速接续与下一步.md)。课件方法和合同流程分别在[01](01_课件学习与证券分析方法.md)、[02](02_任务合同与操作流程.md)；本篇把它们接到实际公司分析、预测和可读图册。

## 1. 这轮最重要的认识

投资分析要完成一条可追索的推理链：**研究问题 → 当前证据 → 可比运算 → 变化与分化 → 经营机制 → 条件预测 → 后续检验**。只把原文和数值整理正确，完成的是证据准备；还需要回答这些事实放在一起意味着什么、哪种解释更值得优先相信、未来可能怎样变化。

同时保留两种态度：对无法确认的原数、动机和因果保持不知道；对已有事实可以支撑的判断，给出明确的优先解释和适用条件。不能用“不能完全证明因果”取消全部研究判断，也不能用故事顺畅填补事实缺口。

本项目曾出现两个实质偏差。第一，把报告写成核验与数值罗列，读者看完仍不知道公司靠什么挣钱及未来怎样；第二，把用户要求“学习参考图册”误当换配色和复刻图形，遗漏参考中的数据、商业机器、品牌及产量预测内容。纠偏标准是**研究问题与解释覆盖有所增加**，不是图数、字数或样式变多。

## 2. 一张总框架：公司怎样把资源变成持续现金

按业务选择分析深度，不把以下各层机械套给所有行业。

| 层次 | 要回答的问题 | 优先观察 | 最容易跳过的连接 |
| --- | --- | --- | --- |
| 客户价值 | 谁选择、为什么购买、替代品是什么 | 产品/客户/使用场景、替代关系、可获得的成交证据 | 管理层定位不等于真实支付意愿 |
| 价值创造 | 产品价值怎样形成，什么难以复制 | 工艺、供给时间、能力、资源与品质披露 | 稀缺叙事不等于经济稀缺或独有壁垒 |
| 价值交付 | 谁获客、交付、服务并承担库存 | 渠道、地区、产品组合、经销及自营责任 | 公司出货不等于终端消费 |
| 价值获取 | 收入怎样变成毛利与净利润 | 匹配量价、成本、税费、渠道及公司费用 | 高毛利不等于渠道净贡献或股东全部收益 |
| 资金回流 | 利润怎样变成现金，谁先垫钱 | 收款、预收/合同负债、营运资本、CFO | 时点余额差不等于期间现金变化 |
| 再投入 | 为维持和扩大经营还要投多少 | 购建现金、库存等待、能力建设、项目时间 | 设计产能不等于当期可售量，低购建率不等于零资本需求 |
| 未来与风险 | 什么条件下增长/回报持续或改变 | 供给释放、需求承接、ASP、费用、现金转换 | 好公司不自动等于便宜证券；经营预测与估值分别补证 |

财务上可以用“收入—利润—资产资本—现金”四环检查完整性；解释上用“创造—交付—获取”组织商业模式。两者相互连接，不是两套彼此独立的报告。商业模式回答钱怎么赚；竞争优势回答为何更容易赚、别人为何难复制；行业与阶段回答机会和约束；预测回答这些机制将怎样演变。

## 3. 从多份任务合同组织研究

先对每份合同保存原件/版本、问题、范围、交付物、核验条件、实际状态。合同更新日期、材料收到日期和研究生成日期分别记录。主合同与生产库存、渠道、现金等延伸合同相互补充，不被局部小任务的格式锁住全局。

把合同问题接成研究顺序：先识别公司和报表边界，再拆商业模式与量价利润，接行业/优势及管理层叙事，最后把生产、渠道、资本现金三条支线汇入未来情景。章节可以保留合同顺序，但读者应看见问题怎样递进。跨合同主题可设商业机器、品牌机制、市场叙事等专题，不能把自己设的专题冒称教师新合同。

用户当前明确要求研究判断和预测时，在授权内推进新增研究；原合同的历史阶段限制、受审版本和采纳仍保留。图册回答了问题，不自动等于所有合同正式关闭、教师验收或新签署。

## 4. 证据先定义“是什么”，再计算“变了多少”

一条数据最少包含：公司/实体、期间、时点或流量、指标定义、原单位、币种、合并范围、表名行列、PDF物理页/印刷页、来源路径及SHA。调整/重述后的比较列与原年当期数各自保留用途。可比性不是数值相近就成立。

本项目原披露用ReviewStore.facts()，变化事实用change_facts()，其他授权域按实际API校验当前来源。摘要、旧导出、参考HTML的HV/SCX、程序跑通和签名都不能替代这个步骤。只重核来源或依赖确实变化的项目，不重新请用户确认未变的有效旧数。

| 身份 | 可以写什么 | 不能越过什么 |
| --- | --- | --- |
| 当前有效Fact | 原披露/已确认计算在当前来源绑定内有效 | 不自动支持新用途、因果或未来 |
| 公司自述 | 公司如何描述优势或解释变化 | 不等于独立因果证明 |
| Agent原件对读 | 实际核过哪些页、原数、单位与上下文 | human_confirmation=false，不冒称人工核验 |
| 附件结构化样本 | 指定附件、样本与定义内的描述统计 | 缺原PDF时不称已核排名/全行业事实 |
| AgentCalculated | 输入、公式、精度和结果可复算 | 算术正确不等于假设真实或机制成立 |
| Interpretation | 优先解释、支持与反例、适用条件 | 最终敲定由人工；不继承旧版本认可 |
| Forecast | 明示假设的未来结果和敏感性 | 不伪装Fact、管理层承诺或统计概率 |
| Unknown / Decision | 缺什么、影响什么；实际研究决定 | Unknown不填零，范围选择不是事实确认 |

这轮增加的119项原件数值/上下文对读与程序页码复核保留在公司primary-source-checks.json；它们没有被写成119项新人工Fact。其他公司原PDF缺位的五公司样本继续单列。原件和完整供应商载荷本地保存，远端发布分析成果、选定必要输入、来源元信息和代码。

## 5. 先发现变化与矛盾，再选择分析手法

### 5.1 不只看增长，找“没有同步变化”的东西

常用组合是：收入与销量/ASP；毛利与净利润；净利润与现金；设计能力与产出；产出与库存/销售；直销份额与平台收入；高毛利与费用/资本占用。总量上升而组成部分下降，往往比单一增长率更能暴露机制变化。

本轮典型问题是：直销扩大却伴随i茅台占比下降；现金下滑快于利润；产量和库存能力增长并不保证当年销售；高毛利可能被渠道内部毛利变化或销售费用侵蚀。先把差异算清，再讨论路径迁移、结构、履约、承接和金融范围，不凭感觉归因。

### 5.2 先拆结构，再谈“价格”和“效率”

收入分公司营业/营业总收入、酒类/其他、产品组、渠道、地区；利润分毛利、营业利润、合并全部净利润、归母。分母必须匹配，避免把主营渠道占比和公司全部营业收入占比混写。合并现金含金融业务时，另做范围桥，不直接当白酒实体现金。

产品组ASP=匹配销售收入÷销售吨数，能用来分析产品组平均实现收入；它同时包含规格、产品、渠道与区域组合变化，不能直接叫同SKU价格或消费者支付价。固定SKU现货、历史电商挂牌和证券价格分别保存。

### 5.3 用勾稽和贡献分解限制叙事

| 运算 | 公式/做法 | 研究用途与边界 |
| --- | --- | --- |
| 同比与百分点 | 同比=X1/X0−1；比例差用pp | 基数为零/负值或口径变化时另说明，pp不是同比 |
| 量价中点分解 | ΔR=ΔQ×(P1+P0)/2+ΔP×(Q1+Q0)/2 | 精确分配Q×P变化；第二项仍是组合ASP作用，非纯提价因果 |
| 结构/内部毛利分解 | G=Σwᵢgᵢ；ΔG=ΣΔwᵢ×均值gᵢ+ΣΔgᵢ×均值wᵢ | 检查渠道结构收益是否被内部毛利抵消；须同类完备口径 |
| 利润桥 | 毛利−税费−各费用+其他净项→目标利润 | 合并、归母及金融/所得税项目明确；不把剩余项伪装单一费用 |
| 库存桥 | 期末=期初+入库−出库±明确调整 | 残差检验定义；基酒和成品不是同一物料，不造一比一桥 |
| 现金覆盖 | 合并CFO−购建长期资产支付现金 | 是算术代理，不是实体FCFF；不能再次扣同一营运资本变化 |
| 期末库存相对出货 | 期末成品吨数÷年度公司出货吨数×365 | 是规模折算，不直接叫会计DIO或终端库存天数 |
| 同日相对价 | 每年median(同日同类型价格A/价格B) | 不等于median(A)/median(B)，须交代样本n、缺日与停更 |

金额归一、舍入只在展示层进行，运算保留Decimal或等效精度。分解结果核加总、库存核残差、预测核逐年量价恒等式；不能只检查公式看起来合理。

### 5.4 对照、相关与反例各自承担什么

同公司跨期比较优先识别变化；同业比较帮助判断相对表征，须交代产品组合、金融业务、税费、费用分类和样本选择。中位数、累计比率、年度比率均值是不同统计量，不能互相替代。五年中位数不是五年合计利润除合计收入。

滞后相关只做诊断：同时报告滞后k、有效n、缺值、共同趋势、结构断点、观察窗口与右删失。五年后销量/某年产量不是物理转化率；相关最大不证明因果时滞，重叠小样本尤其不能给确定预测。有效样本允许分段观察，但不靠挑年份强化故事。

主动寻找同一会计方向的不同经营原因。例如预收下降可由订单/预付变化，也可由交货加快。2007年报关于物流与发货的解释提供一个具体反例，但不能拿旧年原因断定本期原因。反例的用途是设计下一步观测，不是反过来宣布另一原因已成立。

## 6. 让分析像研究，而不是像摘录

一段有用的分析可以采用：**明确判断 → 两三组关键证据 → 过程机理 → 替代解释 → 哪种后续数据能区分 → 对未来参数的含义**。这是一种写作骨架，不要求每段机械六小节。

讲故事时写出行动者、责任和时间：谁投入资源，谁选择/支付，谁交付/确认收入，谁承担费用、库存和资金，最后谁获得现金。对长周期经营，把生产成熟、市场承接、资金回收三种时间并排；库存可以是缓冲，也可以是调整负担，取决于承接与释放。

品牌研究不止列标签。先提机制：识别/信任/使用价值可能提高支付意愿、降低选择或交付成本；再看固定SKU相对价位、公司组合ASP、毛利/费用/资本和现金的共同表征；最后处理产品结构、成本、经销商承担费用、金融范围等替代解释。高毛利支持某种价值获取表征，不单独证明壁垒独有性、因果份额或持续年数。

经营兑现与市场叙事分两条链。经营链是能力/供给→客户接受→公司量价→费用资本→现金；市场链是事件/符号→关联传播→注意力/预期→交易与价格反馈。市场故事可以独立研究，但进入业绩预测时要明确改变哪个经营变量；没有渠道、索取权和隐含预期证据，不从好故事直接下买卖判断。

## 7. 把推断变成可检验预测

### 7.1 不混用三个信息集

本项目2020—2024为主实证，2025单列后验观察并作为本次新预测基期，2026—2028为条件未来。不能用后验资料悄悄证明当年已经知道，也不能把历史合同的时间窗口写成当前全部研究的禁令。

### 7.2 从经营变量逐层搭建

1. **供给检查**：历史基酒/设计能力提供什么；经过陈化、损耗、勾兑、等级与库存释放后多少可以出售。缺参数时给供给参考与Unknown，不用单年t−5产量做全年硬上限。
2. **量价收入**：按产品组Qᵢ,t=Qᵢ,t−1×(1+qᵢ,t)，P同理；R=ΣQ×P+另列其他收入。说明销量是公司出货，ASP是公司组合。
3. **毛利费用**：产品/渠道毛利和销售责任如何变化；管理、研发、税费、金融/其他损益哪些建模，哪些维持基期。
4. **资本与现金**：补可识别的购建、库存与回款；缺实体桥时允许明确命名的合并CFO敏感性，不假装完整现金流估值。
5. **复盘**：实际相对情景的偏差先分到量、ASP、结构、毛利、费用、资本或金融范围，再更新机制与参数。

当前模型采用合并条件利润桥：基期合并净利润+增量保留假设×(酒类毛利变动−销售费用变动)。其中60%是人为增量保留率，不是已核税率；未建模损益保留基期。CFO=条件净利润×设定转换率是敏感性，不能叫实体FCFF或可分配现金。本轮增加供给图，没有静默改变原三年模型、参数和结果。

### 7.3 参数表必须让人看懂判断

每项写变量、年份/单位、数值、来源类型（历史尺度/披露目标/研究设定）、选择理由、什么观测会使其改变。基准是优先工作世界，不是最高概率的统计估计；压力/修复不是置信区间。区间没有概率依据时不配概率。

有用的敏感度是“什么会吃掉增长”：例如核心产品量增1%时，要收入不降，ASP变化需满足1.01×(1+p)=1，即约不能低于−0.9901%。这是条件门槛，不是价格预测。费用率提高1pp对应多少支出也可直接运算。敏感度应服务研究决策，不为了滑块数量做交互。

## 8. 学习参考HTML：先吸收内容，再决定是否复刻外观

逐图建立“参考研究问题/故事→原数据与统计量→本报告已有覆盖→缺什么→当前来源→新增图/专题→自己的推断→修正/不采用原因”。先看图的含义，再读实际HTML字面量数据、配套CSV与原PDF；不要只看截图、标题或标注的核验状态。

本轮实际吸收了商业机器的价值循环、长期收入和现金、设计/实际能力、平台内部结构、同业利润留存、固定SKU价差、叙事兑现和供给时钟。新增内容落回实际合同章节，商业机器/市场叙事设专题。不因“数据应该一致”省掉单位/分母/类型核对；也不重复全部未变旧Fact。

参考中的硬上限、跨准则净利润、中位数与累计比率、CIP列示、不同飞天价格字段、SCX/HV身份都须单独判断。可复用有用的研究问题，同时拒绝不合适的口径或结论。完整读取ZIP目录并识别内容；不执行教师旧工作台的删除或迁移清单。

## 9. 图表选择：一图承担一个可回答的问题

| 图型 | 适合的问题 | 必须留下的边界 |
| --- | --- | --- |
| 年度细线/点 | 同范围水平怎样变、转折在哪 | 缺值断开，多次口径断点分段，后验/未来另标 |
| 单/双列阶梯 | 数值大小、两类同量纲对比 | 精确端点，刻度格不代替数值；多系列标签错开 |
| 哑铃 | 两期或两个变量相距多大 | 空心/实心图例，异时间并列不冒称转化 |
| 构成条带/堆叠 | 组成部分怎样重排，总量如何变 | 厚度/高度编码与图例顺序一致；不把居中位置当经济量 |
| 单期构成 | 一个时点的收入或库存结构 | 小项清楚标示，不能为了简洁藏掉 |
| 贡献桥 | 量价、结构/内部变化怎样勾稽总变化 | 总项与贡献可复算，正负号与起终点准确 |
| 散点/年度垂线 | 两变量关系、阶段是否变 | 每点年份、n和阶段；不默认画因果回归 |
| 离散茎叶/点阵 | 年度离散水平或不可连线样本 | 不造连续趋势，缺项不是零 |
| 条件情景图/滑块 | 哪个假设改变未来多少 | 历史/Forecast分界；参数含义、基期和未建模项可读 |
| 思维导图 | 全景、机制分支、证据和未知怎样连接 | 节点标身份；连线不代因果；能到数量证据 |

图标题直接写研究问题或变化含义，副标题放范围和口径。正文解释研究判断；每图保留三层下拉：①图表分析的含义/用途/推断；②原数、单位、公式、样本和来源；③适用时的图形编码说明。数据表是精确查数入口，图形是认知入口。

思维导图用于总览和查路。本轮分别组织商业机器循环、品牌到财务表征、供给到经营预测。节点写Fact/原件对读/样本/Interpretation/Unknown/Forecast，点击去章节，虚线说明研究关联。当前渲染器为一个中心六分支，是实现选择，不是所有业务必须七节点。

## 10. 图形美观必须通过真实阅读检查

沿用青瓷蓝与暖纸背景可以形成一致风格；不能只靠颜色分组，也不能让浅色曲线失去辨识。常规图/复刻图切换复用相同数据、单位、缺值、断点和分析，只改编码。动画重播不创造新观察，减少动画和打印应可用，离线不依赖CDN。

本轮概览利润/现金曾因并列柱/阶梯与标签太挤而重叠：改全宽、拉开同组中心、缩短横线、错开数值。多系列线图不必每点贴数字，保留悬停/数据表可更清晰。导图中心要实际检查深底文字，不能只相信SVG的fill属性，因为全局CSS可覆盖。窄屏保留图内滚动及键盘聚焦，不能撑宽整个页面。

验收看实际桌面/窄屏截图和DOM几何：图例与编码一致、单位和零基线、精确端点、标签相交、导图21链接、分析下拉、情景控件、风格持久化、打印及减少动画。新图改变几何/数据处理时做有意义测试；纯文档总结不重跑整套财务核验。

## 12. 下一轮如何高效继续

先选最能改变判断的缺口，按“若解释A成立应看到什么；若解释B成立应看到什么”组织补证。当前优先是其余直销承接路径、成熟库存释放、品牌ASP/费用留存及金融现金桥；不是继续无限增加同义图表。

一轮可执行工作是：读取当前入口与所涉合同→调用需要的权威域→列变化/矛盾→复算匹配指标→写优先及替代机制→转成一组可改参数→选择能解释问题的图→更新冲突/当前交接→在既有授权范围内同步成果。以上按问题裁剪，不创造无必要审批、重复核验或固定数量检查。

冲突登记至少写旧值/位置、差别、原件及运算、采用/不采用处理、影响范围、待补和责任身份。两个不同口径均合理时保留两种与各自推演，不为了整齐合并。
