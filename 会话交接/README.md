# 会话交接

此目录保存简短的项目状态、稳定约定和本地操作记录，方便下一次直接定位当前工作，减少重复读取历史文件。

- CURRENT.md：先读，了解当前成果、待办和权威入口。摘要不能证明Fact。
- DECISIONS.md：按需读稳定偏好、授权及口径约定。
- logs/latest-publish.json：按需核对最新提交、推送和弃用标签；其他日志只查本次需要的片段。
- tmp/：临时准备材料；不作为最终证据或成果。

logs/与tmp/仅本地保存、由Git忽略；不要全文加载会话或重新扫描项目。实际Fact须核对投资学工作空间的ReviewStore与当前来源绑定。

下次可直接说明：“先读D:/投资学/会话交接/CURRENT.md，再继续工作。”交接文件便于读取，不会自动清空应用管理的现有聊天上下文。
