# Lec03 专业读本｜商业模式、行业竞争与竞争优势

## 读本用途

本读本用于课前预习和课后复习。课件只讲概要，课堂任务要求学生把本读本中的概念转化为研究问题，再回到年度报告和其他经批准的原始材料完成证据核验。

## 一、商业模式：企业如何创造、交付和获取价值

商业模式不是一句“公司卖什么”，而是回答三个相互连接的问题：

1. 企业为谁解决什么问题，创造了什么价值？
2. 企业通过什么资源、活动、渠道和合作关系把价值交付给客户？
3. 企业如何从客户支付中获取收入，并留下利润和现金流？

分析商业模式时，不要先接受“高端品牌”“技术领先”或“平台优势”等结论，而要拆解为可观察的经营问题。

### 1. 收入来源与收入驱动因素

收入可能由价格、销量、客户数量、交易频率、产品结构、渠道结构或订阅、授权等方式驱动。研究时要问：收入增长到底来自价格、数量，还是一次性因素？客户是否具有持续购买的理由？

### 2. 成本结构与成本驱动因素

成本和费用可能随销量、产能、原材料价格、客户数量、渠道投入或研发投入变化。研究时要问：成本是固定的还是随业务变化的？规模扩大后，单位成本是否下降？

### 3. 资本投入与再投资需求

增长通常需要投入厂房、设备、库存、研发、渠道、品牌或客户获取成本。研究时要问：企业每增加一单位收入，需要投入多少资本？增长是否伴随更高的资本占用和融资需求？

### 4. 利润与现金流转换

会计利润不自动等于现金流。应收账款、存货、合同负债、预付款和资本支出都会影响现金回收。研究时要问：利润是否能够持续转化为经营现金流？现金流是否需要依靠减少投资或增加融资来维持？

## 二、行业分析：先确定企业处在什么竞争系统中

行业分析的第一步不是罗列行业规模，而是划定边界：企业属于哪个细分环节？上游供应商、下游客户、替代品和相邻行业分别是谁？

可以按以下顺序分析：

1. **定边界**：确定行业、细分赛道和产业链位置；
2. **分阶段**：判断行业处于导入期、成长期、成熟期还是收缩期；
3. **找利润池**：分析利润集中在哪些环节，谁拥有定价权和议价能力；
4. **看竞争**：比较竞争者、替代品、进入壁垒和退出成本；
5. **查分配**：判断行业增长最终由谁获得，客户、供应商、渠道还是股东。

行业增长不必然转化为公司利润，更不必然转化为股东价值。竞争者扩产、价格下降、库存上升和资本开支过快，都可能使行业收入增长而回报下降。

## 三、竞争优势：从漂亮叙事变成可核验命题

“护城河”可以作为问题入口，但不能直接作为结论。一个可用的竞争优势命题至少要说明：

- 优势来自什么资源或能力；
- 它如何影响价格、成本、周转、现金流或资本回报；
- 竞争者复制它需要什么条件；
- 这种优势能持续多久；
- 什么证据可能推翻当前判断。

常见的竞争优势来源包括：

| 来源 | 需要观察的结果 | 可能的反方证据 |
| --- | --- | --- |
| 生产优势 | 单位成本、良率、交付速度、规模效应 | 同业快速复制、价格竞争、产能过剩 |
| 消费者优势 | 更高价格、重复购买、客户留存 | 降价才能维持销量、品牌偏好下降 |
| 网络效应 | 用户增加带来服务价值和转换成本 | 用户流失、平台替代、补贴依赖 |
| 牌照与监管壁垒 | 竞争者难以进入、现金流较稳定 | 政策变化、牌照弱化、资本回报下降 |
| 渠道与客户关系 | 获客成本较低、回款较快、客户稳定 | 销售费用上升、客户集中度过高 |

竞争优势只有在能够持续产生高于资本成本的回报，并且不容易被竞争者复制时，才具有投资分析意义。即使企业当前表现很好，也要检查这种表现是否依赖周期高点、短期供给约束或过度资本投入。

## 四、把专业概念转成证券分析问题

| 概念 | 不要直接写成 | 应改写为 |
| --- | --- | --- |
| 品牌优势 | 公司品牌很强 | 是否支持更高价格、更稳定需求或更低获客成本？ |
| 技术领先 | 公司技术领先 | 技术是否形成可观察的产品差异、成本差异或客户留存？ |
| 护城河 | 公司有护城河 | 优势来源是什么，竞争者复制需要什么条件？ |
| 行业成长 | 行业空间很大 | 增长由什么驱动，利润由谁获得，资本回报是否改善？ |
| 商业模式优秀 | 公司模式很好 | 收入、成本、资本投入和现金流之间是否形成可持续的经济逻辑？ |

## 五、与 Agent 协作时的边界

Agent 可以帮助学生：

- 在限定的年度报告中定位收入、渠道、成本、产能和竞争者信息；
- 整理跨期数据和管理层表述；
- 提醒缺失字段、口径问题和反方问题；
- 按任务合同整理过程底稿。

学生必须自己完成：

- 限定原始材料和研究问题；
- 回到年报原文核对页码、期间、单位和口径；
- 判断一项主张属于事实、解释还是预测；
- 保留 Unknown；
- 说明什么证据会推翻自己的判断。

## 六、课后自测

任选一家公司的一个竞争优势主张，写出：

1. 主张是什么；
2. 它对应的收入、成本、资本投入或现金流变量是什么；
3. 需要查找哪些原始材料；
4. 可能的替代解释是什么；
5. 什么证据会使你把它改为 Unknown。
