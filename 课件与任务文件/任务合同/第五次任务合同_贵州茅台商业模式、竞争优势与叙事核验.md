# 第五次任务合同：贵州茅台商业模式、竞争优势与叙事核验

> [!important] 任务定位
> 前四次任务已经训练年报定位、收入信息结构化提取、指标口径识别和变化核验。其现有成果只覆盖有限的收入事实，**不足以直接完成**商业模式、竞争优势与叙事核验。本次用同一家公司、同一研究工作台，围绕新的研究问题多轮执行“定位 → 提取 → 辨口径 → 核验变化”，逐步建立足够的证据基础，再回答：**贵州茅台如何赚钱，其竞争优势可能来自哪里，公司的关键叙事获得了什么程度的证据支持？**
>
> “叙事核验”包括核验公司**说了什么**、已知经营事实**是什么**，并检查机制解释的支持与反证；现有材料不足时保留 `Unknown`。营业收入增长本身不能证明品牌定价权或渠道优势。本课不形成估值或买卖 `Decision`。

本合同是现有“Lec03 任务合同：商业模式与竞争优势证据表”的**贵州茅台案例化执行稿**，沿用其五项结构和成果文件。第五次指连续的学生操作合同编号；课程大纲中的“十二类证券分析任务”是另一层动作分类，不据此改动既有任务主线。

复制本合同到年报研究工作台 `tasks/` 后执行。以下 `sources/`、`work/`、`outputs/`、`evidence/` 均以工作台根目录为基准。学生分发前，教师须在本合同填写最终批准的报告版本与时间边界。

## 二、研究问题

围绕贵州茅台，依次回答三个问题：

1. **商业模式**：公司向谁、通过什么产品和渠道获得收入？收入变化可能对应市场需求、市场份额和平均售价中的哪一项？成本、再投资需求和利润—现金转换如何影响这一模式？哪些连接已经有披露事实，哪些仍只是待检验假设？
2. **行业竞争与优势**：按讲义的“定边界 → 分阶段 → 识别核心矛盾 → 验逻辑 → 防风险”判断公司处于哪个细分市场、产业链位置和竞争阶段，再从讲义的七类来源中选择**一项最值得检验的优势主张**；说明优势来源、作用机制、可观察结果、模仿壁垒和反证条件。
3. **叙事核验**：从批准的年报中找出与上述优势相关的**一条管理层原始表述**，再按该叙事需要重新寻找和核验经营证据。前四次已核验事实能支持其中哪一段？还缺哪些价格、销量、产品结构、渠道、成本或资本投入证据？哪些替代机制可能解释同一结果？

课堂可从已核验的 `T4-01` 出发：2024 年报合并利润表“营业收入”较同报告 2023 年比较列增长 **15.71%**。这是**研究线索**，不是本任务的完整输入包。要解释增长，学生还需取得与具体命题匹配的价格、销量、产品、渠道等证据；如果年报不能提供足够细的变量，应如实标 `Unknown`。

### 讲义知识如何转成取证问题

下表规定研究动作的理论来源。理论只帮助提出问题，不能替代贵州茅台的原始证据；没有可比数据时，记录缺口，不填出看似完整的结论。

| Lec03 讲义位置 | 本任务必须提出的问题 | 优先寻找的证据及边界 |
| --- | --- | --- |
| 3.1 收入来源与驱动 | 产品、地区、渠道中谁贡献收入？增长可能来自**市场需求量 × 市场份额 × 平均售价（ASP）**中的哪一项？ | 已核验的收入结构可作入口；继续找同规格售价或 ASP、销量、可比市场需求。市场份额必须先界定细分市场且有同口径行业分母；总收入增速不能代替三个乘数。 |
| 3.2 成本结构 | 成本随销量或结构变化如何变化？是否存在经营杠杆或规模经济的迹象？ | 营业成本、毛利率、费用和必要的分产品数据；区分价格、产品结构、单位成本和会计分类。年报不足以区分固定与变动成本时保留 `Unknown`。 |
| 3.3 再投资与 3.4 利润—现金转换 | 为增长需要投入哪些资产和营运资本？利润能否转成现金？ | 定位固定资产、在建工程、存货、合同负债、经营现金流与净利润。讲义提出的 CFO／净利润和 FCF／净利润是待检验的转换指标：若分子定义、口径及连续年度可核验，可计算并说明限制；否则写明缺口，交给 Lec04—05。完整的现金流、ROIC 与资本配置判断留给后续课程。 |
| 3.5 竞争优势来源与护城河三问 | 从品牌、成本与规模、网络、渠道、技术、客户关系与转换成本、牌照与监管七类中，哪一种最适合解释茅台？优势有多大、持续多久、扩大规模后能否保持？ | 选择适用的来源，不要求七类全套罗列。若选择品牌，至少提出“价格溢价 → 销量或份额韧性 → 利润率优势”的证据链，并检查产品、渠道和成本等替代解释；同业与长期资本回报证据不足时降低结论力度。 |
| 第四节行业竞争五步法 | 公司在哪个细分市场竞争、处于什么阶段、核心矛盾是什么？哪些经营变量检验该逻辑，什么变化会令其失效？ | 先限定产品、价格带、地域和客户范围，再选与所判阶段相符的竞争问题；未获批准的行业数据不能填成市场份额或行业阶段 `Fact`。选 1—3 个与核心矛盾相连的风险观察变量，不把“高频”自动当作“先行”。 |
| 第五节叙事改写 | 管理层原话怎样变成可反驳命题？ | 固定“优势来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证条件”；可观察结果写明方向、期间、产品与渠道口径，至少列出一个合理替代解释。 |

## 三、材料边界

### 允许使用

- 教师在任务信息中指定的贵州茅台年度报告 **PDF 原稿**。同报告 Markdown 只用于搜索和候选定位。若使用 2020—2024 年多份报告，须逐份列明版本与报告期；不能用 2024 年报的 2023 年比较列冒充已阅读独立 2023 年报。
- 本组前四次任务的过程底稿、阶段成果、`evidence/evidence-log.md` 和 `work/pending-checks.md`。它们提供检索入口、口径先例和少量已核验事实；本任务需要按新问题扩大取证范围，不能只重排旧输出。
- Lec03 主课件、附件2和专业读本，用于选择问题与搭建分析框架；不能作为贵州茅台具体经营事实的原始证据。
- 教师另行明确批准的行业原始材料。未列入材料边界的新闻、股价、研报和 Agent 回答不得直接进入本次证据表。

### 时间、口径与判断边界

- 每条新增 `Fact` 写明材料版本、报告期、PDF 页码或表格、单位、主体与指标口径；由学生本人核验，并在证据日志登记。旧证据可引用已有编号，但引用前须判断是否适用于新命题。
- “管理层说过某句话”与“这句话描述的机制成立”分开。前者可核验为披露事实，后者须另找可观察结果、替代解释和反证。
- 不把品牌知名度、高利润率或收入增长单独等同于可持续竞争优势；不能把不同产品、渠道或年份的数字混算。
- 本任务可以提出待检验的 `Interpretation` 或 `Forecast`，证据不足保留 `Unknown`；按讲义识别现金流转换指标及必要输入，口径可核验时可计算简单比率，不做现金流细分、ROIC 完整计算、估值或买卖建议。

## 四、过程底稿

先在 `work/lec03-claim-notes.md` 列出候选问题、叙事和证据缺口，再在 `work/lec03-evidence-expansion.md` 记录每轮扩展取证。前四次的动作在**每一条新证据链**中重复，但研究对象和材料范围随问题变化：

1. **确定证据链**：先按第四节五步法限定细分市场并提出核心矛盾，再至少安排两轮取证——一轮检验第三节的收入来源或三乘数中的一个关键机制，一轮检验第三、五节中的一项竞争优势叙事。每轮先写明对应讲义概念、命题、待观察变量、需要的期间与口径、允许材料和停止条件。资本投入与现金流是否另开一轮，取决于它们是否为该命题的关键变量；即使本课尚不能完成，也要在经济逻辑图中标出证据缺口。
2. **重复定位与结构化提取**：让 Agent 在批准报告中寻找相关表述、表格和附注，提取产品、地区、渠道、价格、销量、成本、资本投入或现金流的候选资料。逐行保留 PDF 定位、报告期、单位、分类维度和检索失败记录。没有披露的变量不能由总量倒推或猜测。
3. **重复口径识别与变化核验**：学生判断候选资料能否比较，例如“营业收入”与“主营业务收入”、产品销售额与销量、渠道分类的跨年变化。只有两期以上口径可比，才计算变化；出现重述、分类变化或无法统一的口径，就停止计算并保留 `Unknown`。不要求对每项线索机械计算增速。
4. **回到原始材料人工核验**：学生核验被采用的管理层表述和关键数值，新增 `Fact` 进入 `evidence/evidence-log.md`；Agent 候选、未核验数字和修正历史留在过程底稿。每轮注明哪些判断由学生作出。
5. **汇合并挑战机制**：将经过核验的各轮事实放入“收入 → 成本 → 资本投入 → 现金流”和“优势来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证条件”两条链；按讲义的护城河三问检查大小、持续时间与扩张后的保持能力，逐项标注已证实、待查或现有材料无法判断；并列至少一种替代解释、可能的反方证据、当前支持边界和下一步。

每轮使用同一记录字段：研究问题、Agent 候选、PDF 位置、原值、期间与口径、可比性裁决、计算或停止原因、人工核验、证据编号、`Fact / Interpretation / Forecast / Unknown`、反证与待补材料。数量由研究问题和材料披露程度决定；不能为了“多轮”重复抄录同一事实。

## 五、阶段成果

**课堂检查点**：学生先画出讲义第四节要求的细分市场边界，选定两条对应第三、五节的证据链，再完成其中一轮的“定位 → 提取 → 辨口径 → 核验变化或说明为何停止”，并初步写出一条叙事命题。若课堂时间不足，未完成的取证轮次和缺口进入过程底稿，不能把检查点当成整份合同已验收。

完整的 Lec03 阶段成果沿用现有合同的两个文件，不新造一套平行输出：

| 文件 | 应包含的内容 |
| --- | --- |
| `outputs/lec03-evidence-matrix.md` | 至少一条管理层叙事对应的多环节证据链：“原文与定位 → 新旧已核验事实及编号 → 价值驱动变量 → 机制假设 → 替代解释／反证 → 当前状态 → 后续验证”；缺失环节明确标 `Unknown`。 |
| `outputs/lec03-stage-deliverables.md` | 按第四节五步法写出的业务与行业问题清单；按第三节形成的“收入 → 成本 → 资本投入 → 现金流”经济逻辑图；按第三、五节形成的一项竞争优势证据要求表；至少一项本任务中新核验的 `Fact` 和一项保留为 `Unknown` 的记录。 |

后续财务报表、现金流和资本配置检验的问题，应具体写成“需要看哪张表、哪个附注或哪个同口径指标”，交给 Lec04—05。若两轮取证仍不足以判断机制，允许阶段成果停在有证据定位的 `Unknown`，并说明已经查了什么、缺什么、下一步如何取得；不能靠完整措辞补足证据。
