# 第五次任务合同：贵州茅台商业模式验证

> [!important] 任务边界
> 前四次合同训练了年报定位、结构化提取、口径识别和变化核验；现有输出只覆盖有限的收入事实。本任务围绕 Lec03 讲义第三节，**重新运用这四项动作扩展取证**，回答贵州茅台怎样获得收入、承担成本、投入资本并将利润转成现金。这里的“验证”是检查经济逻辑与已披露事实是否相符，证据不足的环节保留 `Unknown`。行业竞争、优势持续性和管理层叙事的综合裁决分别交给第六、七次合同。

复制本合同到本组年报研究工作台 `tasks/` 后执行。下文 `sources/`、`work/`、`outputs/`、`evidence/` 均相对于工作台根目录。执行人、复核人和材料范围须在开始检索前填写。

## 二、研究问题

按讲义第三节的四环节，形成一张“**收入 → 成本 → 资本投入 → 现金流**”经济逻辑图，并分别回答：

1. **收入（3.1）**：主要产品、地区和渠道怎样贡献收入？`市场需求量 × 市场份额 × 平均售价（ASP）`中，哪些驱动有可用证据，哪些仅是候选解释？
2. **成本（3.2）**：营业成本、费用及毛利率怎样随收入与产品结构变化？现有披露能否区分规模经济、价格变化和成本变化？
3. **投入（3.3）**：维持和扩大业务需要哪些资产、存货与其他资本占用？现有材料能否判断新增收入的再投资需求？
4. **现金（3.4）**：利润与经营现金流之间有什么可观察差异？讲义的 CFO／净利润、FCF／净利润需要哪些统一口径的输入？

可从第四次任务证据 `T4-01` 的 2024 年营业收入同比增长 15.71% 开始，但该事实不回答增长来自价格、销量或产品结构中的哪一个驱动。

## 三、材料边界

- 原始事实优先取自学生材料清单列出的贵州茅台 2020—2024 年年度报告 PDF；在任务信息中写明本组实际使用的年度和版本。同报告 Markdown 仅供搜索，不作为最终证据。不得把 2024 年报里的 2023 年比较列说成已经核验了独立 2023 年报。
- 前四次底稿和证据日志可提供指针。每项新 `Fact` 由学生回到 PDF 核对版本、页码、期间、单位、主体和口径，再登记证据编号。
- Lec03 讲义与读本用来提出问题，不能证明贵州茅台的具体事实。行业需求和市场份额若缺少获批准的同口径行业分母，只列为待核验问题，不自行估计。
- 产品、地区、渠道分解属于不同维度，不能跨维度相加。无法统一报告期、指标定义、会计分类或合并范围时停止比较并标 `Unknown`。
- 本任务可识别或在口径充分时计算简单现金转换比率；不展开 FCFE／FCFF、营运资本周转、ROIC 或资本配置的完整评价，不作竞争优势和投资 `Decision`。

## 四、过程底稿

将扩展取证写入 `work/task05-business-model-checks.md`：

1. 学生从四环节中选择最关键的收入驱动，并列出其余三环节需要的证据与缺口。
2. Agent 在批准报告中**读取、定位、整理、提取线索、发现遗漏**，形成候选表；每行保留 PDF 页码候选、表名、期间、单位、业务维度与原值。
3. 学生逐项完成口径裁决和原文核验。只有可比时才复算变化；候选、修正、失败和停止原因都保留在底稿。
4. 将已核验事实、机制解释与未知分栏；给每项解释写一种可替代机制。例如，收入增长也可能来自产品结构而非同款产品提价。

每行至少记录：讲义概念、研究问题、Agent 候选、PDF 精确定位、期间与口径、人工核验、证据编号、`Fact / Interpretation / Unknown`、支持边界及下一步。不能为填满四环节而把未披露变量猜成数字。

## 五、阶段成果

输出 `outputs/task05-business-model-map.md`，包含：

1. 四环节经济逻辑图，每一环标出已核验事实、可能的作用关系与缺失证据。
2. 一张关键变量表：收入结构与收入驱动、成本及毛利率、再投资需求、利润—现金转换；对不能计算的项目写明原因。
3. 至少一项本任务中新核验的 `Fact`、一项合理替代解释和一项 `Unknown`。
4. 给第六次合同的交接卡：当前商业模式可能影响竞争位置的变量是什么，哪些优势主张仍需行业或同业证据？

课堂检查点只要求完成**一条收入或成本证据链**的定位、提取、口径判断及人工核验／停止记录；完整四环节图可在后续完成。检查点不等于合同验收。
