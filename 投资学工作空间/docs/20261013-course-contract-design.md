## 2. 产品主线与状态

主导航：研究概览 → 材料 → 提取与口径 → 核验与计算 → 商业/行业/叙事 → 情景与估值 → 报告 → 合同与历史。概览只给当前问题、准备状态、下一动作和待人工项，默认一次显示一张待核卡。

| 状态轴 | 必须显示 | 程序可做 | 人工关口 |
| --- | --- | --- | --- |
| 材料 | 缺失、已导入、已冻结、来源改变 | 文件检查、SHA、版本和页面/字段目录 | 批准材料范围、用途与研究时点 |
| 记录 | 候选、待核、有效、失效、撤回；保持原字面状态 | 字段完整性、重复/单位/依赖检查、动态有效性读取 | 按原规则亲查或有效授权确认，禁止导入自动确认为Fact |
| 判断 | Fact、Interpretation、Forecast、Decision、Unknown | 展示分类、证据引用、范围及缺失字段 | 机制、行业阶段、可比材料、预测假设和决策终判 |
| 计算 | 可计算、已复算、待核、停止；输入有效性独列 | 确定公式、精确运算、显示精度、停止条件 | 可比性/经营属性裁决和新结果确认依现有规则 |
| 合同 | 未开始、课堂检查点、内容待验收、内容验收、签署、关闭 | 逐条映射、计数、输出链接、缺口汇总 | 条款验收、真实签署和关闭，不能由文件存在自动关闭 |

“有效Fact”仍须显示该Fact支持什么；研究用途排除不等于撤销原值。不同域重叠不得算作多条独立证据。Unknown必须可提交、可导出，不要求填假值才能过下一步。

## 5. 报告生成规格

按钮“生成报告草稿”组装已保存的结构化输入、当前有效证据、计算和人工文字；生成前读取当前来源/依赖，不靠旧导出件判Fact。缺章可导出，列明未完成原因；不自动补研究观点或强行关闭合同。

| 报告部分 | 输入 | 生成内容与规则 |
| --- | --- | --- |
| 封面与研究边界 | 公司/证券、问题、会计期、信息截止、材料清单、责任 | 版本、生成时点、材料范围；事后分析和历史可获性分开 |
| 直接回答 | 已审阅解释/采纳事件、有效依据 | 经营表现与年度变化→暂定机制及替代→增强/保持/走弱对象→具体未知和改变判断的数据；未采纳标草稿 |
| 证据与计算 | 当前接口结果、候选、口径卡、计算依赖 | Fact/候选/Unknown分栏；原值、单位、主体、两种页码、公式和精度；失效项不作为有效Fact |
| 经营与行业 | 四环、五步、优势五环/三问、年度事件 | 图表由明确数据生成；不同维度不相加；相同证据不重复算独立支持 |
| 叙事审计 | 原话、支持/挑战/未决、替代/反证、人工表述 | 原话与机制分开；显示范围、失效条件和当前采纳状态 |
| 情景与估值（可选） | 显式假设、模型与价格、所需输入 | 标模型/Forecast，不冒充事实或本课原验收；缺参数写停止原因 |
| 风险与下一步 | Unknown、冲突、人工待裁决、后续财务问题 | 只显示下一项核验与其余待办入口；每项缺什么、查过哪里、影响什么、如何补 |
| 合同与历史附录 | 原稿SHA、条款映射、真实事件、签署记录 | 分开课堂/内容/核验/签署/关闭；新旧版本并列；同人身份真实保留 |

## 6. 可执行验收与优先级

P0先完成可信骨架：主流程导航、空白新项目、材料冻结、证据/Unknown表单、一次一张核验卡、动态接口读取、确定性计算/停止、报告组装、100项条款映射与历史。

P1完成研究体验：商业四环/行业五步/叙事审计可编辑；年度变化/依赖与冲突；来源原页联动；熟练表格、筛选与输入复用；可读图表和打印报告。

P2是显式输入的财务、情景、估值和组合模型；无完整输入/授权时显示准备度和Unknown。可选AI只提出草稿/遗漏，需标明实际接入状态和人工裁决。

验收必须证明：

1. 新公司只带方法与空模板，没有茅台Fact、品牌/阶段结论或lxy授权。
2. 导入CSV/新候选、打开原页、计算完成和签署均不自动形成Fact。

4. Fact、Interpretation、Forecast、Decision、Unknown与候选/有效性状态均能读懂，颜色之外有文字说明。
5. 不能确定单位/主体/范围/可比性时可以保存Unknown；零基数/未桥接重述等停止且报告解释原因。
6. 第五次两版独立显示；检查点不当完整验收；第六允许完整缺口路径；第七写回既定两文件。
7. 支持与挑战可并列；同一原值变化/原载同比/推演不互换；历史可获性未知不会显示“无前视”。
8. 报告包含来源与公式；未采纳机制标草稿；来源失效项不作为有效Fact；无用户观点时只组装空模板/缺口。
9. 当前合同版显示后续补齐，旧待补段可追溯；真实核验actor、时间及旧签署字节不改。
10. 页面在手机/桌面可使用，长中文/金额/绝对路径不溢出；键盘可操作；保存状态/错误/停止原因可见；无需用户编辑JSON。
