# 人工核验：选择、确认、自动记录

双击工作空间根目录的[人工核验入口.cmd](../人工核验入口.cmd)。首次默认显示C01、C02，默认核验人取合同中的Leo；可以改名字，姓名也可以后补齐。

1. 本人回到原PDF完成核验。窗口显示数值、页码和口径，可点“打开原PDF”。第一次核验包括版本、期间、单位、合并主体、表名、注释与支持边界。
2. 选中已核验通过的记录，点“确认所选为Fact”。核验日期、来源和位置自动保存，证据账本、成果表、合同核验状态及任务进度自动同步。
3. 有疑问时填写可选备注，点“保留Unknown／撤回”。可批量选择；历史保留，之前的确认不会被悄悄抹去。

默认选中条目不等于确认，开窗不改变任何核验状态。点确认是本人对所选原文与数值的核验声明；它只确认披露及所示口径，不证明品牌、因果机制或未来投资价值。

## 第四次任务

切换到“变化可比性”。核对窗口显示的两期原值与七项条件；全部核对且可比时可用总确认，也可逐项勾选。点“保存并复算”得到结果，再由本人检查输入与计算结果。来源或数据变化后须重新确认。

第一次的C01、C02通过不自动勾选七项。缺少确认、原件改变、比较基数为零或可比性不成立时，停止计算并显示原因。

## 复核与签署

数据核验结果和正式合同签署分别记录。人名和签署可以以后统一补齐，程序不会替你签署或自动关闭合同。其余任务的实际取舍与反证仍由本人审阅。

## 自动更新与恢复

记录保存后自动更新相关文件，后续研究可以直接读取已确认Fact。若提示部分视图未同步，记录本身仍保留，修复提示中的问题后刷新同步即可。旧生成脚本已加保护，已有人工填写时停止重建。
