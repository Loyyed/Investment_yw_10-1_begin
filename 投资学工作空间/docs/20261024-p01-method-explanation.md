# P01方法解释与待修订处

用户真实答复：“对是否认可P01四项口径，我存在疑惑和疑虑说说你这么处理的道理吧”。这不是认可、拒绝或撤回旧原数；当前P01未认可，旧115项Fact与原展示不变。

P01-1的初步选定科目来自合同的选择性代理要求，算术透明，但经济分类未完成。回查2011年报PDF73页（印刷72页），预付款附注确有征地拆迁款、未完工工程中标单位款项。这是Agent新定位，未新增为本人Fact。建设预付不能全部解释为日常营运周转；应拆日常周转与长期建设预付，检查在建工程等是否重复。若只是从NCWC移到建设预付资本，合计资本未必改变，不应机械剔除全部建设预付。P01-1须完善后再请认可，不能用“代理”标签代替分类工作。

P01-2平均资本是用年度利润流量匹配当年两端资本存量的简便近似。2007年初25.24亿元、年末43.45亿元，简单平均34.35亿元；2011平均79.18亿元。使用同报告年初是为避免直接拼接旧准则原年报；仍不证明全年时间加权平均或与上年原披露完全一致。有季度/投入时间数据时可改善。

P01-3旨在检查营业利润含金融/投资因素与税率改变的影响，基准和整行移除方案只是两种算式。2011基准/平均资本116.84%，整行方案113.48%，不能把其中任一直接称实体ROIC；高于100%本身不证明错误，也不证明成熟新增资本回报。报表有效税率34.41%/25.01%，两路径平均拆分中税率因子约7.93亿元，仅为公式作用，不认定税法因果。新回查2011年报PDF85—86页（印刷84—85页），财务费用有利息、汇兑和手续费明细，投资收益也有来源。应补读与核验这些明细，整行移除降为临时敏感性，不能长期用Unknown或本人认可代替可做的补证。

P01-4保留正式指标停止原则：资本余额变化同时受新增、折旧/摊销、处置、重分类和营运变化影响，不等于累计现金再投资；2007→2011四年两个端点不能识别新增利润究竟来自旧资本、提价/税率还是新资本成熟。四年不足证明每笔成熟，不等于否定公司全部投入成熟或否定高回报；应继续研究可获年度与项目映射，不能把所有结论笼统挂起。

当前建议：第2项保留为标注近似的计算约定，第4项保留证据限制；第1、第3先由Agent补分类与明细后修订，再逐项请本人判断。原数、科目归属、公式结果与研究结论分开，用户不承担替Agent证明技术口径正确的责任。本轮不重新计算或改写原P01工作簿，不创建认可/签署。
