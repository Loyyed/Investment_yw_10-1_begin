# 第三次任务合同：年报指标口径识别

> [!important] 使用边界
> 名称相同或数值接近，不代表两个指标可以相互替换。
>
> Agent 可以并列整理候选口径、比较差异并提醒遗漏，但 Agent 输出不是证据，也不能替学生选择口径。
>
> 学生必须回到教师指定的年度报告原文核验，再根据指标边界、报表主体、报告期、单位、会计口径、来源位置和研究用途，决定采用或排除哪些候选值。

## 二、研究问题

第二次任务得到的候选记录中，哪些指标适合描述集团收入总体规模、收入结构和归属于母公司股东的净利润？哪些候选不适用？哪些问题仍然无法确认，需要保留为 `Unknown`？

本任务只识别指标口径并说明取舍理由，不计算变化幅度，不解释经营原因，也不评价商业模式、竞争优势或投资价值。

## 三、材料边界

### 允许使用

- 教师指定的年度报告 PDF；
- 同一年度报告的 Markdown，仅用于搜索和候选定位；
- `outputs/revenue-structure-table.md`；
- 已核验的 `evidence/evidence-log.md` 和仍未解决的 `Unknown` 清单。

### 使用与记录要求

- 不能以“数值看起来正确”“数字彼此接近”“Agent 推荐”或“通常这样用”作为选择理由；
- 不删除被排除的候选和初选错误；
- 不混用合并财务报表与母公司财务报表口径；
- 不把无法确认的指标强行归入某一口径；

### 本任务不能支持的结论

- 本任务只能完成口径识别，不能据此解释变化原因，也不能形成预测、估值或买卖判断。

## 四、过程底稿

每个候选指标单独成行，写入：

```text
work/metric-scope-candidates.md
```

每行至少记录：候选编号、原文指标名称、候选数值、指标边界、报表主体、会计口径、报告期或时点、单位与币种、报表与附注、来源位置、与研究问题的关系、人工核验状态、当前判断状态。

- **人工核验状态**：待核验 / 核验通过 / 核验未通过；
- **当前判断状态**：本任务只使用 `Fact` 或 `Unknown`，不在这一阶段写入 `Interpretation`、`Forecast` 或 `Decision`。

人工比较和选择口径的过程写入：

```text
work/scope-adjudication.md
```

至少处理 1 组收入口径冲突和 1 组利润口径冲突，并完整保留一次修正过程：“初选错误 → 发现冲突 → 回到原文 → 修正口径”。

## 五、阶段成果

经人工核验并确认的口径卡写入：

```text
outputs/metric-scope-decision.md
```

口径卡先写明研究用途和采用的指标，再说明该指标的边界、报表主体、会计口径、报告期、单位与币种。随后指向对应的收入结构表和证据位置，并列出被排除的候选、排除理由和仍未解决的 `Unknown`。

口径卡中核验通过且可以标为 `Fact` 的记录，由学生按 `evidence/evidence-log.md` 的既有字段登记并取得证据编号。被排除的候选和 `Unknown` 不登记为已确认的证据。

# 本人口径裁决说明（根据本次答复整理）

本次以贵州茅台2024年度报告为依据，围绕集团收入总体规模、收入结构及归属于母公司股东的净利润，对C01—C12十二项候选进行重新比较。报告期为2024年1—12月，金额单位为人民币元；根据报表主体、指标定义、利润归属、会计口径及研究用途区分主指标、结构项、桥接项和补充项，不因名称相近或数值接近而相互替代。

**主指标采用C01、C02、C03。** C01为合并利润表“其中：营业收入”，用于描述集团商品与服务营业收入；C03为合并利润表“一、营业总收入”，用于描述包含金融业务利息收入的集团营业总收入，两者必须分别标明边界。C02为合并利润表“1.归属于母公司股东的净利润”，在本次描述未扣非归母净利润的研究用途下，是唯一正确的主指标。

**结构项采用C04、C06、C07。** C04为合并利润表单列的“利息收入”，是C03的组成项，可用于核对C03与C01的金融业务利息差额；不得单独代表集团收入，也不得重复加计至C03。C06、C07分别为合并附注40中的“主营业务”和“其他业务”收入，其合计与C01对应；两项均作为收入结构使用，不单独替代全集团收入。

**补充项采用C12。** 第5页主要会计数据中的“归属于上市公司股东的扣除非经常性损益的净利润”为合并口径，作为扣非归母净利润独立列示，保留其补充用途；其扣非定义与C02不同，不能替代本次归母净利润主指标。

**C10保留为桥接对照，不列入本轮七项采用清单。** 合并利润表“2.少数股东损益”表示不属于母公司股东的损益，可用于核对“全部净利润＝归母净利润＋少数股东损益”的归属关系，不能代表归母净利润。

**明确排除主指标替代用途：** C05为母公司个别利润表营业收入，不能替代集团合并收入；C08为财务费用中的利息收入抵减项目，不属于营业收入或营业总收入的收入组成项，不能与C04混同或加进C03；C09为含少数股东损益的全部净利润，不能替代归母净利润；C10为少数股东损益，不能归入母公司股东盈利；C11为母公司个别利润表净利润，不能替代集团归母净利润。此外，C04单独用作集团营业收入或营业总收入亦不适用。上述限制针对研究用途，不撤销已核实的披露原值，也不删除被排除候选。

### 初选、冲突、回到原文与修正

# 本次真实修正过程

## 初选及旧版处理

本人最初将C01—C12十二项候选列入选择范围，随后比较报表主体、收入定义及利润归属。旧版最终采用C01、C02、C03、C04、C06、C07六项，C04限作金融业务利息差额对照；C12因不能替代C02，被排除在旧版采用清单之外。旧版答复曾将C12与母公司数据并列，整理时已纠正其实际定义为合并口径的扣非归母净利润。本轮不删除旧答复及整理纠正历史，旧版成果加弃用标记。

## 发现冲突

收入方面，C01与C03的边界不同，C04仅是C03的金融业务利息组成项；C05属于母公司个别报表，C08列于财务费用，均不能替代集团营业收入。C06与C07属于收入结构，可合计对应C01，不能各自代表集团全部收入。利润方面，C09含少数股东损益，C10仅为少数股东损益，C11属于母公司个别报表；三者均不能替代C02。C12的合并主体正确，但扣非定义与C02不同，“不能替代主指标”不等同于“没有补充用途”。

## 回到原文及对应位置

依本人本次明确提供的重新比较结果，按原有候选核验表填写对应PDF位置：第63页为合并利润表C01、C03、C04、C08；第64页为合并利润表C02、C09、C10；第65、66页分别为母公司利润表C05、C11；第108页为合并附注40中的C06、C07；第5页主要会计数据为C12。既有原值核验事件及时间完整保留；本次聊天记录用途修正，不生成新的PDF原值核验事件，不虚构新的核验时间。

## 本轮修正后的选择

将笼统采用改为按角色使用：C01、C02、C03为主指标；C04、C06、C07为结构项；C12为独立补充项。最终七项采用清单为C01、C02、C03、C04、C06、C07、C12。C02继续作为本次未扣非归母净利润的唯一正确主指标，C12不得替代C02。C04仅作收入结构及差额对照，明确排除单独代表集团收入的用途。C10作为利润归属桥接对照保留，不加入七项采用清单；C05、C08、C09、C10、C11均排除主指标替代用途。

本次修正承接真实的十二项初选和旧版六项处理，重点是重新划分使用角色，并将C12从旧版采用范围外调整为独立补充项。原始候选、原值Fact、旧版用途结论及本次修正均保留；姓名与正式签署仍待统一补齐。
