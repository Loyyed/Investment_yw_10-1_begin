## 三、材料边界

### 允许使用

- 教师指定的公司年度报告；
- 项目规则允许使用的行业材料；
- `evidence/evidence-log.md` 中已经人工核验并取得编号的证据记录；
- `work/pending-checks.md` 中尚未解决的冲突与 `Unknown`；
- `outputs/revenue-structure-table.md`；
- `outputs/metric-scope-decision.md`；
- `outputs/change-verification-record.md`；
- Lec03 主课件与专业读本。

### 时间与证据限制

- 决策时点之后的信息不得回填到当时判断；
- 口径尚未明确、未经人工核验，或无法指向原始材料的记录，不能标为 `Fact`；
- “品牌强”“技术领先”“护城河深”等标签不得直接作为事实或结论；

### 本任务不能支持的结论

- 多个 Agent 给出相同答案不等于独立验证；
- 不把相关性直接写成因果，不把摘要替代原文；
- 本课不展开财务报表勾稽、现金流细分、会计口径修正、估值或买卖建议。

## 四、过程底稿

候选叙事、变量、证据要求、替代解释和待核验问题写入：

```text
work/lec03-claim-notes.md
```

每条记录分四步填写：

1. 写清问题：研究问题、管理层主张；
2. 写清证据：原始材料与版本、精确定位与证据编号、已核验事实；
3. 写清解释：机制假设、可观察变量、合理替代解释、反方证据；
4. 写清边界：支持边界、当前状态、后续验证。

如果涉及竞争优势，还须补充优势来源和模仿壁垒。

五种状态必须分开使用：`Fact / Interpretation / Forecast / Decision / Unknown`。本课可以记录 `Fact` 和 `Interpretation`，也可以提出留待后续检验的 `Forecast`；证据不足时保留 `Unknown`。本课不直接作出买入、卖出等 `Decision`。

## 五、阶段成果

经人工核验的叙事—变量—证据矩阵写入：

```text
outputs/lec03-evidence-matrix.md
```

其余阶段成果写入：

```text
outputs/lec03-stage-deliverables.md
```

本课提交五项成果：

1. 业务与行业问题清单；
2. 叙事—变量—证据矩阵；
3. 以“收入 → 成本 → 资本投入 → 现金流”呈现的商业模式经济逻辑图；
4. 沿“优势来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证条件”展开的竞争优势证据要求表；
5. 两项人工核验记录：一项记录经过核验、可以标为 `Fact` 的内容；如有必要，可在此基础上写出 `Interpretation`。另一项记录因证据不足而保留为 `Unknown` 的内容。

这些成果只是研究底稿。Lec04—05 将继续检验其中的机制假设；它们还不是完整的公司分析报告，也不是最终投资结论。
