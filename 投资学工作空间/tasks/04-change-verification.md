# 第四次任务合同：年报指标变化核验

> [!important] 使用边界
> 公式本身不能完成核验。Agent 可以整理候选值、检查字段和复算公式，但不能判断两期是否可比，也不能解释变化原因。
>
> 只有学生确认报告期、单位、报表主体、合并范围和指标定义均一致或具有可比性，才能计算变化。即使变化已经核实，也不能据此直接认定变化机制。

本合同复制到年报研究工作台 `tasks/` 后执行；下文所有 `work/`、`outputs/` 和 `evidence/` 路径均以该工作台根目录为基准。

## 二、研究问题

在第三次任务已经明确口径的指标中，哪一项可以进行同口径比较？本期相对比较期发生了什么变化？这项变化最多能够说明什么？

本任务只回答“指标发生了什么变化”，不回答“为什么变化”。价格、销量、产品结构、成本、资本投入、现金流和竞争位置等机制，留到 Lec03 再提出和检验。

## 三、材料边界

### 允许使用

- 教师指定的年度报告 PDF；
- 同一年度报告的 Markdown，仅用于定位；
- `outputs/revenue-structure-table.md`；
- `outputs/metric-scope-decision.md`；
- 与所选指标对应的已核验证据记录。

### 停止计算条件

出现以下任一情况，停止计算并回到口径识别：比较期数为零；指标定义变化；合并范围变化；单位或币种不同；前期数据重述；无法确认两期是否同口径。

如果无法可靠调整，就应保留为 `Unknown`。不能用“估计可比”代替核验，也不能仅凭变化事实认定需求改善、品牌增强或竞争优势扩大。

## 四、过程底稿

候选值、公式、冲突与修正写入：

```text
work/change-verification.md
```

至少记录：指标名称、本期数与报告期、比较期数与比较基数、单位、报表主体与口径、原文限制、计算公式、代入值、舍入规则、当前状态、人工核验记录。

常用同比变动幅度：

```text
变动幅度 =（本期数 − 比较期数）÷ 比较期数
```

计算前必须先完成可比性判断；计算过程必须能够复算。

## 五、阶段成果

人工核验后的变化记录写入：

```text
outputs/change-verification-record.md
```

阶段成果只记录经过核验的变化事实、这些事实最多能说明什么，以及仍未解决的 `Unknown`。它可以作为 Lec03 提出机制假设的事实依据，但不能直接作为机制解释。

核验通过且可以标为 `Fact` 的变化记录，由学生按 `evidence/evidence-log.md` 的既有字段登记并取得证据编号。已经停止计算或仍无法确认的记录，继续留在过程底稿中，并标为 `Unknown`。

## 六、验收

- [ ] 已核对两期材料、报告期、比较基数、单位和币种；
- [ ] 已核对报表主体、合并范围、指标定义和重述情况；
- [ ] 公式、代入值、结果和舍入规则均可复算；
- [ ] 原文限制、冲突和修正过程完整保留；
- [ ] 不可比或仍无法确认的内容已停止计算并标为 `Unknown`；
- [ ] `Fact` 只描述变化事实，没有混入机制解释；
- [ ] 核验通过的 `Fact` 已写入 `evidence/evidence-log.md` 并取得证据编号；
- [ ] 没有根据阶段成果直接作出预测、估值或买卖建议；
- [ ] 执行人和复核人已签署。
