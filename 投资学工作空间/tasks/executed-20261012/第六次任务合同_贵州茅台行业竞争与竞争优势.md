## 二、研究问题

**行业竞争五步法：**

1. **定边界**：茅台的核心产品在什么产品、价格带、客户和地域市场竞争？处于产业链什么位置？不能直接用整个白酒行业的数据代表该细分市场。
2. **分阶段**：该细分市场处于什么生命周期阶段？需求、增长、竞争者和集中度的哪些证据支持这一判断？缺少行业证据时保留 `Unknown`，不预设为成熟期。
3. **识别核心矛盾**：在所判阶段，关键问题是扩张效率、护城河与利润归属，还是替代风险？哪些环节获得利润、谁有议价能力？
4. **验逻辑、防风险**：用什么经营和财务变量检验以上判断？选 1—3 个与核心矛盾有传导关系的风险观察变量，写明什么变化会推翻判断。

**竞争优势：**从讲义七类来源——品牌、成本与规模、网络、渠道、技术、客户关系与转换成本、牌照与监管——中选择**一项与茅台最相关的候选优势**，回答“来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证条件”，并检查护城河三问：优势多大、能持续多久、规模扩大后还能否保持。若选择品牌，重点考察**价格溢价、销量或份额韧性、利润率优势**是否相互印证。

## 三、材料边界

- 贵州茅台 2020—2024 年年度报告 PDF、第五次已核验成果，以及教师在任务信息中明确批准的行业或可比公司**原始材料**。报告 Markdown 只用于检索；每项关键 `Fact` 回到原始 PDF 或获批准的一手来源核验。
- 没有同口径的细分市场需求、销量分母或可比公司数据时，不计算市场份额，不评价“高于同行多少”。不能用管理层自述替代独立的行业事实。
- 同业利润率差异须先核对产品结构、渠道、地区、期间与会计口径；本任务若材料尚未覆盖同业比较，只写证据要求，不制造排名。
- 高频指标不自动等于先行指标。行业阶段、利润池和壁垒若缺少足够证据，分别标 `Interpretation` 或 `Unknown`。
- Agent 用于定位候选资料和提示缺口；学生负责定市场边界、筛选可比材料、核验事实及解释机制。本任务不作估值或买卖 `Decision`。

## 四、过程底稿

写入 `work/task06-industry-advantage-checks.md`：

1. 按五步法逐步填写市场边界、阶段候选、核心矛盾、待观察变量与失效条件。每一步先写**需要什么证据**，再让 Agent 定位候选材料。
2. 重新执行定位、结构化提取、口径识别及必要的变化核验，至少为一项行业或竞争位置判断增加新证据；无法取得独立行业材料时如实记录已查范围与 `Unknown`。
3. 对候选优势沿“五环节”填写机制链，并保留至少一种替代解释。例如，利润率较高可能来自产品结构、成本或渠道，而未必证明品牌定价权。
4. 记录护城河三问每一问的证据状态与缺口；跨期或同业材料不足时，明确留给后续核验。

每项被采用的事实记录来源版本、页码或段落、期间、单位、市场定义和人工核验；Agent 候选与学生裁决分栏。
