## 二、研究问题

从批准的贵州茅台年报中选一条能够精确定位的管理层表述，例如与品牌、渠道、需求或增长有关的表述。先核验原话，再回答：

1. 这条表述所声称或暗示的**经济机制**是什么？可映射到收入三乘数、成本、再投资、现金流或竞争位置中的哪个变量？
2. 若机制成立，应观察到什么方向、期间、产品与渠道口径的结果？第五、六次已核验事实支持到哪一步？
3. 哪些替代机制同样可以解释现有结果？有哪些反方证据，或需要主动寻找什么反方证据？
4. 现有材料允许作出的**最大可辩护表述**是什么？什么新证据会使它失效，哪项财务检验交给 Lec04—05？

例如，第四次任务的 `T4-01` 只证明营业收入同比增长 15.71%；第五、六次若没有取得同口径价格、销量、份额和利润率证据，就不能把增长写成“品牌定价权增强”。

## 三、材料边界

- 使用教师指定的贵州茅台 2020—2024 年年报 PDF、第五和第六次已核验成果及证据日志；其他行业或同行原始材料须在任务信息中明确批准。Markdown 与 Agent 输出只用于定位和整理。
- 管理层表述可作为“披露事实”登记，但不因此把表述中的因果关系登记为 `Fact`。引述须给出版本、页码、段落与上下文；新经营事实须由学生亲自回原文核验并登记编号。
- 不把高利润率、收入增长或多名 Agent 的一致回答当作独立的竞争优势证明。相关性和单年证据不能代替机制与持续性检验。
- 价格、销量、产品结构、渠道、地区、行业分母和会计口径不一致时，先停止归因；缺少关键环节时保留 `Unknown`。
- 本任务形成研究命题与证据边界，完整报表勾稽、现金流和资本配置检验留给 Lec04—05，估值与买卖判断留给后续课程。

## 四、过程底稿

写入 `work/task07-narrative-audit.md`：

1. **原话定位**：Agent 在批准材料中找候选，学生回 PDF 核对原文、版本、报告期与上下文，记录这句话究竟说了什么。
2. **命题改写**：沿讲义“优势来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证条件”拆解；若是非优势叙事，也写清相应价值驱动变量和反证。
3. **补缺取证**：按命题所需重复前四次的定位、提取、口径识别与变化核验，只补关键缺口；不能因为前两次已有输出就停止找证据。
4. **正反核验**：分栏列出已核验支持事实、挑战事实、未决问题和替代解释；检查是否用了同一产品、客户、渠道、地区与期间口径。
5. **人工裁决**：逐条写明 `Fact / Interpretation / Forecast / Unknown`、现有证据的支持边界、最大可辩护表述、失效条件与下一步。Agent 仅协助查找和发现遗漏，裁决由学生完成。

保留被否定的候选、口径修正和失败记录；不以流畅的结论代替缺失证据。
