# 年报研究工作台模板

> 用于《投资学》第 2 单元的课堂实操。复制本目录后，将其改名为你的研究标的名称，例如 `贵州茅台_2024年报研究/`。

## 目录说明

| 位置 | 放什么 | 谁可以修改 |
| --- | --- | --- |
| `sources/` | 教师批准的年度报告、公告等一手材料 | 原始文件只读，不改写 |
| `tasks/` | `Research Mandate`、任务合同、待办问题 | 研究者可以维护 |
| `work/` | 过程笔记、Agent 运行记录、待核验线索 | 研究者可以维护 |
| `evidence/` | 人工核验的证据日志、冲突与 `Unknown` | 研究者可以维护 |
| `outputs/` | 阶段提交和最终研究产物 | 研究者可以维护 |
| `CLAUDE.md` | Agent 的项目规则、材料边界和输出标准 | 教师或项目负责人维护 |

## 本课最低任务

1. 将指定年报放进 `sources/`；
2. 在 `tasks/first-task.md` 填写第一次任务；
3. 在 `work/notes.md` 保存过程笔记和待核验线索；
4. 在 `evidence/evidence-log.md` 完成至少两条人工核验；
5. 在 `outputs/first-analysis.md` 写出阶段性输出与边界；
6. 用 Git 保存一次可回看的版本快照。

> [!warning]
> 不要把密码、API Key、个人隐私、未公开材料或未经教师批准的资料放入工作台或版本记录。
