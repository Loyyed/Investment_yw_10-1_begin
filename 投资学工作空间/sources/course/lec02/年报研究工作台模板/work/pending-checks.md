# 年度报告待核验证据清单

> [!important] 使用边界
> 本文件是**过程底稿**，用于记录 Agent 或人工定位到、但尚未完成**证据核验**的线索。线索不是 `Fact`，也不能直接进入投资判断。
>
> 每一条线索都必须回到任务合同指定的年度报告 PDF，核对页码、表名或位置、报告期、单位、会计口径与上下文。只有完成全部必要核验的内容，才能转入 `evidence/evidence-log.md`，形成可审查的证据记录。

## 使用方法

- 在 Markdown 阅读视图中直接点击 `- [ ]` 前的方框；确认后会变为 `- [x]`。
- 每完成一项核验，在对应位置补充定位、数值或说明，再勾选方框。
- 若无法确认，不要勾选；在“问题与人工修正”中记录原因，并保留为待核验线索或 `Unknown`。
- Agent 只承担读取、定位、整理、提取线索与发现遗漏；研究者负责核验证据并承担判断。
