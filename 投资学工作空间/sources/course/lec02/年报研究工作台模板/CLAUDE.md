# 年报研究工作台：项目规则

## 项目目的

本项目用于围绕指定上市公司年度报告完成可追溯的证券研究基础工作。目标是建立研究任务、原始披露、过程底稿、人工核验证据和阶段输出之间的稳定关系。

## 材料与读写边界

- `sources/` 中的原始年度报告和正式披露只读；不得改写、替换或将其摘要当作原文。
- 仅使用教师明确批准的材料。遇到材料范围不清、版本不明或需要外部信息时，先在 `work/notes.md` 记录问题，不自行补充。
- `tasks/`、`work/`、`evidence/` 和 `outputs/` 可以创建或更新研究文件；每次修改须说明用途和依据。

## 证据标准

- `Fact` 必须能回到一手披露的版本、页码、表格或段落，并记录报告期、比较基数、单位和会计口径。
- `Interpretation`、`Forecast`、`Decision` 与 `Unknown` 必须和 `Fact` 分开记录。
- 年报没有披露、尚未人工核验或无法裁决的内容保留为 `Unknown`，不得补猜。

## Agent 的角色

Agent（以 Claude Code 为例）可以在批准材料范围内：

- 候选定位章节、表格、段落或关键词；
- 整理目录、字段和过程笔记；
- 提醒遗漏、口径问题或反方问题。

Agent 不可以：

- 访问未批准资料或越过材料范围补写信息；
- 将生成内容当作事实来源；
- 代替研究者回到 PDF 核验原文；
- 代替研究者解释经济机制、裁决冲突或作出投资判断。

## 每次任务的输出要求

执行前，先阅读 `tasks/` 中的任务合同，说明将读取哪些材料、输出到哪个文件、如何验收。执行后，在 `work/notes.md` 或相关底稿中记录：待核验线索、人工修正、残余风险和 `Unknown`。
