# 第一次任务：定位并核验一项年度报告披露

## 1. 研究对象与问题

- **研究对象：** 贵州茅台 2024 年年度报告
- **研究问题：** 请定位合并利润表中的营业收入和归属于上市公司股东的净利润，并说明这些数字的报告期、单位、表格位置和可以支持的最小事实。

## 2. 材料与时点边界

- 只读取 `sources/` 中教师指定的贵州茅台 2024 年年度报告及其课堂批准的检索稿；
- 不读取新闻、研报、行情、搜索结果或其他未批准材料；
- 不形成买卖建议、目标价、未来业绩预测或投资结论。

## 3. 工作要求

1. 先列出拟查看的章节、表格或关键词，并说明为什么；
2. 如使用 Agent，要求其只提供待核验定位线索和表格结构整理；
3. 回到原始年报 PDF，核对页码、表格名称、报告期、单位和上下文；
4. 将过程问题写入 `work/notes.md`；
5. 将人工核验结果写入 `evidence/evidence-log.md`；
6. 将阶段性结果写入 `outputs/first-analysis.md`。

## 4. 验收标准

- 每项数字有精确的年报定位；
- 明确记录报告期和单位；
- 区分“年报披露的事实”与“对经营表现的解释”；
- 写出至少一项该数字不能直接支持的结论；
- 如果 Agent 提供过线索，记录人工如何确认或修正。
