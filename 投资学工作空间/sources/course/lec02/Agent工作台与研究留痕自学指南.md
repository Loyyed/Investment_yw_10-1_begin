# Agent 工作台与研究留痕自学指南

> 本指南用于复习第 2 单元的课堂内容，并帮助你在另一家上市公司年报上重复练习。它不替代课堂模板、原始年报核验或教师要求。

## 一、先复习：工作台、流程和聊天不是一回事

| 概念 | 它回答什么？ |
| --- | --- |
| 一次聊天 | 当前这个问题怎样得到一次回答？ |
| 研究工作台 | 材料、规则、任务、过程、证据、输出和版本放在哪里？谁能读写？ |
| 证据核验流程 | 一条主张如何从待核验线索变为可追溯的 `Fact`？ |

工作台是一种项目环境。它至少应有：

```text
README.md       项目目的、目录和交付标准
CLAUDE.md       Agent 的材料边界、读写规则和证据标准
sources/        原始年报，只读
tasks/          研究任务与任务合同
work/           过程笔记、待核验线索、人工修正
evidence/       已人工核验的证据日志
outputs/        阶段和最终产物
.git/           版本、差异与提交历史
```

## 二、用另一家公司重复一次最小任务

1. 复制 `年报研究工作台模板/`，并将目录改成新的研究对象；
2. 将教师批准的年度报告放入 `sources/`；
3. 在 `tasks/` 写下一个只做“定位与提取”的任务；
4. 在 `work/` 记录阅读过程、待核验线索和修正；
5. 回到 PDF，将人工确认的内容写入 `evidence/`；
6. 在 `outputs/` 写阶段结果，并说明支持边界；
7. 用 Git 或等价记录保存一次版本快照。

不要一开始就要求 Agent 给出公司质量、估值或买卖判断。先把一条可以回到原文的记录做对。

## 三、Agent 的最小安全边界

### 可以请 Agent 做的事

- 在批准的年报中定位候选章节、表格或关键词；
- 整理目录、字段和过程笔记；
- 提醒缺少页码、期间、单位、口径或支持边界；
- 提出反方问题，帮助发现遗漏。

### 必须由人做的事

- 明确研究问题、材料范围和输出要求；
- 打开 PDF 核对版本、页码、表格、期间、单位、口径和上下文；
- 区分 `Fact`、`Interpretation`、`Forecast`、`Decision` 与 `Unknown`；
- 决定接受、修正、拒绝或保留一项待核验线索；
- 对研究判断承担责任。

### 不应做的事

- 提供账号、密码、API Key、个人隐私或未经批准资料；
- 让 Agent 访问未批准材料或写入项目外目录；
- 将 Agent 回答直接当作 `Fact`；
- 跳过权限、自动接受编辑或绕过人工检查；
- 为了得到一个答案而填补年报没有披露的内容。

## 四、Git：研究过程为什么值得保存？

Git 让你能够回答：**我在何时、基于什么材料、以什么理由改了哪项研究记录？**

| 最小动作 | 研究含义 |
| --- | --- |
| `status` | 当前哪些文件改变了？ |
| `diff` | 改前和改后具体有什么不同？ |
| `commit` | 保存一组已经人工检查过的研究进展 |
| `revert` | 发现错误后撤回修改，同时保留错误发生过的历史 |

每次保存前先检查：是否混入原始材料、临时文件、密码、Token、个人资料或未经批准的内容。第 2 单元只做本地留痕练习，不连接远程仓库。

## 五、Skills、MCP、plugin 与 Subagent：按问题选，不按名词堆

| 概念 | 适合解决什么问题 | 什么时候不该用 |
| --- | --- | --- |
| Skill | 重复出现且已验证的检查流程 | 任务尚未稳定、事实尚未核验时 |
| MCP | 经批准后连接额外资料或工具 | 来源、权限或口径不清时 |
| plugin | 组织分发经过审核的命令、模板和流程 | 只为“功能更多”而安装时 |
| Subagent | 明确且可核验的子任务、独立复核 | 想把投资判断责任交出去时 |

后续课程会进一步讨论：第 4—5 次课的财务研究底稿、Skills 与 memory；第 8—9 次课的 Subagent、MCP、plugin、最小权限和反方检验。本课最重要的不是配置这些组件，而是理解它们不会降低你的证据责任。

## 六、遇到问题时的恢复顺序

```text
停止
→ 确认任务和材料边界
→ 检查项目规则与文件位置
→ 查看过程笔记和版本差异
→ 记录问题
→ 修订任务、走人工路径或请教师确认
```

常见问题：

| 情形 | 正确处理 |
| --- | --- |
| Agent 找不到目标页码 | 不要求它猜；用目录、关键词和 PDF 手工检索，记录待核验问题 |
| 数字存在但单位或期间不清 | 回到表格标题、脚注和前后文，无法确认则保留 `Unknown` |
| 误改原始年报或放错文件 | 停止写入，恢复原件，将文件移回正确目录，并记录错误 |
| 输出像结论但没有证据 | 收窄为待核验主张，补充页码、表格、口径与支持边界 |

## 七、下一次练习的自查清单

- [ ] 我能解释每个工作台目录的职责；
- [ ] 我的任务写清了目标、输入、边界、输出和验收；
- [ ] 我的每条 `Fact` 能回到指定年报 PDF；
- [ ] 我把待核验线索与人工核验证据分开保存；
- [ ] 我知道本次修改了什么、为什么修改；
- [ ] 我没有把 Agent 输出当成事实或投资结论；
- [ ] 我知道什么时候应保留 `Unknown`。
