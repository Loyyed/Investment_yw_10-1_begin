# AI 时代的证券分析师导读：受监督的研究助手

## 角色边界

Agent 是受监督的研究助手，不是事实来源、投资决策者或责任主体。它可以降低资料检索、文本抽取、表格整理和初步对比的成本；但它也可能出现事实错误、时点混淆、来源遗漏和不经说明的推断跳跃等问题。

因此，证券分析师和投资者的关键工作不会因为有了 Agent 而消失：定义问题、冻结资料边界、核验信源、解释商业模式、发现遗漏条件、裁决冲突，并对关键判断负责。

## 典型的受监督Agent投研流程

```text
Mandate → Evidence → Analyze → Challenge → Adjudicate → Decide
研究任务 → 证据 → 分析 → 反方审计 → 人工裁决 → 决策
```


| 环节       | Agent 可以做什么           | 人必须做什么                                   |
| ------------ | ---------------------------- | ------------------------------------------------ |
| Mandate    | 复述任务、指出缺口         | 定义投资问题、材料和时点边界                   |
| Evidence   | 抽取、整理、标注来源位置   | 判断来源是否原始可信、口径是否一致             |
| Analyze    | 比较、计算、生成初步结构   | 解释商业模式，区分事实与推断                   |
| Challenge  | 提出反方问题、寻找遗漏变量 | 判断反方问题是否关键，补充证据                 |
| Adjudicate | 整理冲突信息               | 裁决冲突、保留 Unknown                         |
| Decide     | 生成结构化决策卡草稿       | 在价格、估值、期限和投资组合约束下作出关键判断 |

## 典型失误


| 看起来合理的输出                              | 实际问题                               | 应如何处理                                                     |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------- |
| “贵州茅台品牌强，护城河深。”                | 把公司披露或研究假设写成已验证事实     | 标记为 Interpretation，补充外部与跨期资料                      |
| “2024 年现金流增长，所以未来价值必然提高。” | 从过去事实直接跳到未来与价值结论       | 拆解营运资本、现金集中管理安排和一次性因素，写明 Forecast 条件 |
| “根据最新资料，当前应当……”                | 混入材料范围外信息，且越权形成现实建议 | 回到任务边界，保留为 Unknown 或后续资料需求                    |
| “年报显示……”但没有位置                    | 不可核验                               | 要求章节、表格或段落定位，并人工抽查原文                       |

## 最小核验闭环

每一条关键主张至少应留下五项记录：

1. 它是 Fact、Interpretation、Forecast、Decision 还是 Unknown？
2. 它的原始来源、报告期、口径和位置是什么？
3. 它的适用边界和关键假设是什么？
4. 什么反方问题或新证据可能推翻它？
5. 下一步还需要谁来核验、裁决或补充什么证据？
