# 五种判断类型：贵州茅台案例与练习

这份材料帮助你严格区分 `Fact`、`Interpretation`、`Forecast`、`Decision` 与 `Unknown`。它们不是五种句式，而是投资研究中五个不能相互替代的判断位置（position）。

## 一、五种判断类型的定义


| 类型           | 定义                                                   | 需要满足的条件                             | 常见错误                       |
| ---------------- | -------------------------------------------------------- | -------------------------------------------- | -------------------------------- |
| Fact           | 已经发生、可追溯到原始可信来源并能独立定位、复核的事实 | 有一手来源、报告期、口径和位置             | 把公司评价或自己的结论写成事实 |
| Interpretation | 对事实为何如此发生的机制解释                           | 说明从哪些事实推演出什么机制，并保留替代解释 | 从一组相关数字直接跳到因果结论 |
| Forecast       | 对未来状态的条件化判断                                 | 写明假设、时间范围、观察指标和失效条件     | 把过去趋势外推成确定结果       |
| Decision       | 在当前价格或估值、期限和投资组合层面的约束下采取的行动 | 说清行动、决策时点、约束和改变条件         | 用“公司好”作为投资行动的依据 |
| Unknown        | 现有材料无法裁决、但会影响判断的问题                   | 明确不知道什么，以及下一步如何取得证据     | 用看似合理的猜测填补空白       |

> [!important]
> 一条判断可以从 Fact 开始，但不能跳过 Interpretation、Forecast 与 Unknown，直接变成 Decision。

## 二、案例 1：高毛利率到底说明什么？


| 类型           | 示例                                                                       | 为什么属于这一类                               |
| ---------------- | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| Fact           | 贵州茅台 2024 年茅台酒毛利率为 94.06%，系列酒毛利率为 79.87%。             | 数字可定位于年报“主营业务分产品情况”表。     |
| Interpretation | 产品结构与品牌定位**可能**共同支撑了茅台酒显著高于系列酒的毛利率。         | 这是对数字的机制解释；“可能”提示它仍待验证。 |
| Forecast       | 如果产品组合、终端需求和定价能力保持稳定，整体毛利率可能维持在较高水平。   | 它谈的是未来，成立依赖多个尚未验证的条件。     |
| Decision       | 在没有比较当前估值与市场隐含利润率之前，继续研究，不因高毛利率直接买入。   | 它规定了当前行动，并承认定价信息缺失。   |
| Unknown        | 当前价格是否已经充分反映长期高毛利率？竞争、渠道与需求变化是否会压缩毛利率？ | 现有年报没有回答这些问题。                     |

### 请判断下列句子

1. “茅台毛利率高，所以股票肯定被低估。”
2. “年报显示茅台酒毛利率高于系列酒；这种差异是否可持续，还需要研究品牌、渠道和需求。”
3. “如果毛利率保持不变，未来利润一定增长。”

**参考判断：** 第 1 句把 Fact、Interpretation 与 Decision 混为一谈；第 2 句合理地区分了事实和待验证解释；第 3 句将条件化 Forecast 误写成确定结论。

## 三、案例 2：渠道变化能否直接证明护城河？


| 类型           | 示例                                                                                           | 为什么属于这一类                               |
| ---------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| Fact           | 2024 年直销收入为 748.43 亿元、毛利率为 95.33%；批发代理收入为 957.69 亿元、毛利率为 89.42%。  | 数据来自年报“主营业务分销售模式情况”表。     |
| Interpretation | 直销与批发代理之间的毛利率差异，可能反映渠道组合和利润分配方式不同。                           | 这解释了差异，但尚未证明哪种渠道的财务绩效更优。 |
| Forecast       | 若直销占比继续提升且没有显著增加销售与市场推广费用、渠道运营或履约成本，公司盈利结构可能改变。 | 未来结果依赖直销占比与相关成本的共同变化。     |
| Decision       | 先补充渠道费用、终端库存和经销关系资料，再判断渠道变化是否改变长期现金流。                     | 这是下一步研究行动，而不是对股票的立即判断。   |
| Unknown        | 直销增长是否来自真实终端需求？是否伴随更高的获客、履约或渠道维护成本？                         | 年报表格不能单独回答。                         |

### 反方问题

> 直销毛利率更高，为什么不等于直销一定更好？

因为毛利率只反映收入减营业成本后的比例，不能自动覆盖销售与市场推广费用、渠道运营或履约成本、渠道稳定性、库存压力、现金回收和经销网络价值。

## 四、案例 3：增长质量应怎样判断？


| 类型           | 示例                                                                                                           | 为什么属于这一类                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Fact           | 2024 年营业收入同比增长 15.71%，归母净利润同比增长 15.38%，经营活动现金流净额同比增长 38.85%。                 | 数字均可定位于年报近三年主要会计数据表。 |
| Interpretation | 经营现金流增速快于收入和净利润增速，**可能**是值得研究的增长质量信号。                                         | 这是一个合理线索，但不是结论。           |
| Forecast       | 如果现金流改善主要来自可持续的经营回款，未来自由现金流可能继续受益。                                           | 必须先验证现金流变化的来源与能否延续。   |
| Decision       | 在拆解营运资本、现金集中管理安排及其对经营现金流列报的影响和一次性影响因素之前，不把现金流增速直接用于上调估值假设。 | 这是对模型输入的审慎处理。               |
| Unknown        | 经营现金流增长中，有多大比例来自销售回款、营运资本变化、现金集中管理安排或一次性影响因素？                       | 年报的概括说明不足以完成完整归因。       |

### 判断训练

请把下面句子改写得更严谨：

> 经营性净现金流大涨，说明茅台未来肯定更有价值。

可参考的改写：

> 年报显示经营性净现金流同比增长 38.85%。这可能增强对盈利现金含量的初步判断，但仍需拆解回款、营运资本、现金集中管理安排及其对经营现金流列报的影响和一次性因素；在此之前，不应直接据此提高未来现金流预测或估值结论。

## 五、案例 4：品牌叙事怎样进入研究？


| 类型           | 示例                                                                   | 为什么属于这一类                             |
| ---------------- | ------------------------------------------------------------------------ | ---------------------------------------------- |
| Fact           | 年报将品质、品牌、工艺、环境和文化称为五大核心竞争力。                 | 这是公司披露了什么，事实是“公司这样表述”。 |
| Interpretation | 品牌与工艺可能通过消费者支付意愿、定价能力和渠道议价能力影响长期盈利。 | 这是研究者的机制推断，不是年报已证明的结论。 |
| Forecast       | 如果消费者支付意愿和稀缺性不被显著削弱，品牌溢价可能继续支持长期盈利。 | 未来仍可能受需求、竞争、政策和消费偏好影响。 |
| Decision       | 将品牌叙事列为待验证的研究假设，而不是直接把“品牌强”填入估值模型。   | 决定了下一步研究如何做。                     |
| Unknown        | 外部消费者数据、竞品替代、年轻群体偏好和渠道库存是否支持这套品牌叙事？ | 年报不能独自回答。                           |

## 六、三步检查法

面对任何一句分析，依次问：

1. **它在说过去、现在，还是未来？** 过去发生且能定位的，才可能是 Fact。
2. **它跨过了哪一步？** 从数字到机制、从机制到未来、从未来到行动，每一步都要补充假设和证据。
3. **如果它错了，什么证据会推翻它？** 回答不出来，就把它降级为 Interpretation 或 Unknown，不要写成结论。

> [!success] 最小合格表达
> “年报显示 ________（Fact）。这可能意味着 ________（Interpretation），但成立取决于 ________（条件）。我们还不知道 ________（Unknown），所以目前采取 ________（Decision）。”
