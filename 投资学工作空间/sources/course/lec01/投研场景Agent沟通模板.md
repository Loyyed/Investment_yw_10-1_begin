# 投研场景 Agent 沟通模板与使用说明

## 使用原则

每一次与 Agent 协作前，先确定以下事项：研究目的、使用场景、材料和时间边界、允许与禁止操作、验收标准，以及必须由人裁决的问题。以下模板用于课堂训练，不输出现实买卖建议。

## 反例：一句话为什么不够？

> 帮我分析一下贵州茅台。

它没有说明服务什么判断、材料是否限定、报告期是什么、是否允许外部搜索、如何引用来源，以及什么算完成。Agent 可能因此混入了报告期外的内容、生成了无出处数字，或者错误地把管理层叙事写成了结论。

## 模板 1：受限年报事实抽取

**适用场景：** 从已冻结的一份年报中建立事实底稿。

```text
请仅基于【公司】的【报告期】年度报告，建立事实底稿。

研究目的：本任务服务于【研究问题】，不形成现实买卖建议。
材料与时间边界：只允许使用【文件名／路径】；不得补充报告期外信息。
允许操作：提取、整理和比较年报中的商业模式、产品、渠道和财务指标。
禁止操作：不得把管理层表述改写为独立结论；不得补充未声明外部资料；不得给出买卖建议、目标价或仓位建议。
输出要求：每条信息注明 Fact / Interpretation / Forecast / Decision / Unknown，并给出章节、表格或段落定位。
完成标准：先列出 3—8 条可核验 Fact，再列出 Unknown 与需要人工裁决的问题。
请先复述你的理解，并指出任务中仍不明确的条件。
```

## 模板 2：五种判断类型标注

**适用场景：** 审计一段已有分析文字，识别推理跳跃。

```text
请仅根据下列文本和允许材料，为每个关键句标注 Fact、Interpretation、Forecast、Decision 或 Unknown。

对每个非 Fact 的句子，说明：它依赖哪些事实、隐含什么假设、至少一种替代解释，以及需要什么证据才能提高可信度。
对每个 Fact，保留来源、报告期、口径与位置。无法定位的内容标为 Unknown，不得补写来源。
不要形成现实买卖建议。

文本：
【粘贴文本】
允许材料：
【列出材料】
```

## 模板 3：护城河假设的证据与反证

**适用场景：** 将“品牌强”“渠道好”等叙事改造成可检验假设。

```text
请把下列竞争优势主张拆成待检验的商业模式。

主张：
【例如：公司披露称品牌是核心竞争力】
允许材料：
【年报及明确允许的外部资料】

请按表格输出：当前可定位 Fact；主张尚不能说明什么；可观察指标；需要的后续证据；潜在反证；触发重审的信号。
将公司披露、研究者 Interpretation 与 Forecast 分开。不要把任何单项证据写成“护城河已被证实”。
```

## 模板 4：红队审计

**适用场景：** 对小组的初步解释进行反方挑战。

```text
你现在是红队审计助手。请审计以下初步解释，但不要替代人作出最终结论。

初步解释：
【粘贴小组解释】
事实底稿与来源：
【粘贴 Fact 及定位】

请输出：
1. 推理中最可能被遗漏的 3 个条件；
2. 每个条件的一种替代解释；
3. 能推翻或削弱该解释的外部或跨期证据；
4. 仍应保留的 Unknown；
5. 需要由研究者人工裁决的事项。
```

## 模板 5：初始 Decision Card 整理

**适用场景：** 将已核验的课堂材料整理成下一步研究计划。

```text
请根据以下已核验材料整理一张初始 Decision Card。

限制：没有价格、估值、持有期和投资组合层面的约束时，不得输出买卖建议。

请依次填写：
- 当前已确认的 3 条 Fact（带定位）；
- 暂时成立的 1 条 Interpretation（含替代解释）；
- 最大的 2 个 Unknown；
- 最关键的 2 条反方问题；
- 下一步需要的价格、估值、行业或外部资料；
- 当前行动：继续研究或暂缓判断，以及理由。

请明确哪些部分必须由人核验或裁决。
```

## 提交前的人工核验清单

- [ ]  所有关键数字都能回到原始可信来源；
- [ ]  报告期、口径和材料边界没有混淆；
- [ ]  公司披露、研究解释和未来预测没有混写；
- [ ]  所有关键解释保留了替代解释与反方问题；
- [ ]  Decision 没有越过价格、估值、期限和投资组合层面的约束；
- [ ]  Unknown 被显式保留，并写明下一步证据。
