## 二、贯穿整个课程的三条主线

课程旨在解决一个核心问题：面对一家上市公司，如何厘清三层叙事——公司的自我陈述、市场流传的叙事与预期、研究者自行构建的投资命题——从而识别价值创造、判断市场预期，并形成一个可证伪的投资命题？

三条主线共同服务这一核心问题，逐层落实：**投研全流程**定阶段，**8 步判断链**定问题，**任务主线**定动作。

**投研全流程**

```text
Mandate → Evidence → Analyze → Challenge → Adjudicate → Decide → Log & Review
```

**8 步判断链**

```text
公司的业务是什么 → 公司说了什么 → 公司实际上如何赚钱 → 历史财务是否支持这个故事
→ 市场正在相信什么 → 价格要求什么未来 → 什么会证明我错 → 我是否愿意为这个判断负责
```

**任务主线（十二类任务）**

```text
证据获取   定位 · 结构化提取 · 口径识别
    ↓
证据分析   变化核验 · 证据冲突 · 跨年度比较 · 主张核验
    ↓
投资判断   同业比较 · 盈利预测 · 估值 · 催化剂与风险
    ↓
持续研究   财报后的模型与投资逻辑更新
```
