# 金融专硕《投资学》课程建设：项目协作规则

项目概览、目录结构与阅读入口见 `README.md`。

## 项目定位与内容来源

本项目是面向金融专硕《投资学》的长期课程建设项目，课程内容来源包括我的 Wiki 及外挂目录中的相关资料。可以借鉴和复用这些资料中已经整理好的内容，但不得改动被引用资料的原件。

## 分层

项目按照“课程设计大纲”与“具体开课记录”分层维护，不能因为一次具体授课覆盖课程设计大纲。目录与资产按需新增，不为形式完整预建空目录或空文件。`原始资料/` 存放课程设计引用资料的副本（供学生分发），`Agent实操演示/` 保存教师课堂演示的动态材料（文件随演示更新）。

## 课程本体论

本课程以 Agentic Securities Analysis 为主轴，不把 Agent 工具应用与证券分析知识的讲授视为彼此独立的内容，而是将专业知识讲授与 Agent 驱动的证券分析任务实操无缝衔接。这一原则贯穿课程教学始终。

年报是最重要的原始资料来源，投资认知提供理论知识框架，Agent 提供分析工具，学生与教师负责判断。human-in-the-loop 贯穿整个课程，培养认知能力、品味、审美和判断力，是课程教学的首要目标。

面对一家上市公司，如何厘清三层叙事——公司的自我陈述、市场流传的叙事与预期、研究者自行构建的投资命题——从而识别价值创造、判断市场预期，并形成一个可证伪的投资命题？

## 课程逻辑

后续课程单元、课件、案例、作业和评价须服务于同一条投资判断形成链：

```text
公司的业务是什么
→ 公司说了什么
→ 公司实际上如何赚钱
→ 历史财务是否支持这个故事
→ 市场正在相信什么
→ 价格要求什么未来
→ 什么会证明我错
→ 我是否愿意为这个判断负责
```

## 证据审计纪律

每项关键主张明确标记为 `Fact`、`Interpretation`、`Forecast`、`Decision` 或 `Unknown`；`Fact` 必须回到一手来源并保留日期、版本、页码或段落定位，冻结时点之后的信息只能进入后续复盘，不得回填至当时判断。Agent 输出不是证据、也不是最终投资判断，其检索、提取、计算、解释与反方观点均须经人工核验后才能进入课堂或正式材料；案例须记录决策冻结时点、可用材料边界、关键反证与失效条件。

## 命名与结构

课程单元名称统一使用专业术语，单元之间保持直观的逻辑一致性与授课内容的完整性。`教学内容/` 下的长期单元以 `lecXX_主题` 命名，候补专题以 `候补专题_主题` 命名；不另造概念，也不用“第 XX 单元”等易与长期单元混淆的表述。课程内容文件的 frontmatter 至少包含 `title`、`course_id`（统一 `mf-investments`）、`unit`、`status`、`updated`。

## 工具引入

课程设计服务于证券分析任务；Agent 工具应用相关知识，只有能够改善证券分析学习时才作为讲授对象。
